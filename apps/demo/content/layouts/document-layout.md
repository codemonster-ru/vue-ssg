# Document Layout

`CmDocumentLayout` is the main layout primitive for documentation pages.

## Sidebar + Content + Aside

Use the three-column mode when the page has:

- left navigation
- central article content
- right-side table of contents

## Sticky Regions

Enable `sticky-header`, `sticky-sidebar` and `sticky-aside` when the docs site
needs a persistent navigation frame while the article scrolls.

## Mobile Behavior

The sidebar and aside are hidden at narrower widths. Provide drawer controls so
readers can still reach navigation and the table of contents.
